

**Drone Digital Twin – Flight, Environment & Health Monitoring**

This project implements a simplified Drone Digital Twin using Python. The system simulates drone flight while monitoring important parameters such as battery level, speed, GPS position, altitude, weather conditions, wind effects, and obstacles.

The simulation models different environmental conditions and their effects on drone behavior. Battery consumption changes based on weather conditions, while wind can affect the drone's speed. Obstacles can introduce GPS deviation and altitude variations.

The system also performs basic health monitoring by checking battery level, altitude, and GPS drift. Alerts are generated when abnormal conditions are detected.

The simulated data is stored and visualized using Matplotlib. The project generates graphs for battery level, drone GPS path, and altitude throughout the simulation.

**Technologies Used:** Python, Random, Matplotlib

**Key Concepts:** Drone simulation, Digital Twin, Robotics, GPS navigation, environmental modeling, health monitoring, anomaly detection, data logging, and data visualization.

**Objective:** To demonstrate how a Digital Twin can be used to simulate, monitor, and analyze the behavior of an autonomous drone under different environmental conditions.
